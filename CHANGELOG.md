# Changelog

## 0.1.0-alpha.1 — 2026-11-18

First public **source** release of IBQgram.

- Current five-petal IBQgram identity, light/dark artwork and native monochrome menu-bar template.
- Classic contact/chat windows backed by Telegram Desktop, messaging, file/media handling, groups/topics and bot commands.
- Independent settings/account/about windows, local statuses, optional status sharing and macOS notifications.
- Complete source patches against pinned public Telegram Desktop and WebView revisions; no private repository dependencies.
- English and Turkish documentation, current promotional artwork and local publication audit.
- Clean public Git history; no original recordings, private session data or retired design materials.
- GitHub Actions disabled; validation runs locally.

This is an early macOS Apple Silicon development release. No signed/notarized application installer is supplied. See the README for current limitations.
